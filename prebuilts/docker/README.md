# Adaption Steps

Copy/paste the entire docker/ folder into your new repository.

1. Search all docker/ directory files for `ROBOTNAME` and replace all instances with the name of the robot this is for
2. Search all docker/ directory files for `REPONAME` and replace all instances with the name of the repository this is going into
3. Search the Dockerfile for all instances of `UPDATEME` and fill in the values that you want
4. Search all docker/ directory files for `TODO` and do what the comment tells you to do. You may delete the comment after
